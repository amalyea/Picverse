# Picverse

Picverse is a responsive art gallery website designed and developed as an individual project for the Human Computer Interaction course at BINUS University.

The project provides a visual platform where users can explore artworks, discover creative communities, and share their own work through a simple and engaging interface.

## Live Website

[View Picverse on Vercel](https://picverse-iota.vercel.app/)

## Project Overview

Picverse was created to explore how interface design, visual hierarchy, and responsive development can improve the experience of discovering digital artwork.

I designed and developed the project independently using HTML, CSS, JavaScript, and Figma.

## Key Features

- Responsive landing page
- Artwork gallery and discovery pages
- Artwork creation and submission interface
- Community exploration
- Sign-in and login interfaces
- Navigation across multiple pages
- Responsive layouts for different screen sizes
